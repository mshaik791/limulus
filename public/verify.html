LIMULUS

Paste a receipt to check it. Verification uses only the receipt and the public key inside it.
    How this works. A receipt carries a hash over its contents and an Ed25519 signature over that hash. Verification recomputes the hash from what you pasted and checks the signature against it, so any edit fails both. You can run the same check yourself with node src/verify-receipt.ts receipt.json without contacting us.
